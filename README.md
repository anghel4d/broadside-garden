# Broadside Garden

Broadside Garden is a declarative workspace for cultivating selected research signals into reproducible experiments, prototypes, and reusable systems.

## Intended loop

1. Register a research signal, question, or opportunity.
2. Frame a falsifiable hypothesis or concrete design objective.
3. Build the smallest useful experiment or prototype.
4. Record inputs, configuration, observations, and results.
5. Preserve successful work as a reusable component or documented technique.
6. Retire unsuccessful branches without losing what they taught.

## Design principles

- Nix is the canonical installation and configuration interface.
- Experiments should be isolated, reproducible, and inexpensive by default.
- Inputs, dependencies, configurations, and results retain provenance.
- Exploratory work must not silently become production infrastructure.
- Reusable outputs are promoted deliberately rather than by accident.
- External publication and consequential actions remain under human control.

## Status

Initial repository scaffold. Languages, experiment conventions, and package boundaries have not yet been selected.
